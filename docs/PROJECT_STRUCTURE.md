# Final source structure

The repository is split into two zones:

- **Active runtime:** `apps/web`, `scripts/rakshak_api.py`, current model/evidence/policy modules, current artifacts, tests.
- **Research history:** `research/archive/` contains superseded scripts and experiments and is not part of the runtime path.

The active runtime uses one canonical API entrypoint: `scripts/rakshak_api.py`.
